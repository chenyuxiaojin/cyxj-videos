# Fable 5 指南，找到你的未知

2026-07-09 发布。拆解 Anthropic 工程师 Thariq 的长文 *A Field Guide to Fable: Finding Your Unknowns*，讲怎么让 AI 帮你找出「你不知道自己不知道」的东西。

视频里提到的**两个 Claude Code Skill** 就放在这个文件夹里，免费拿去用。

> 这两个 skill 原先单独放在 [CYXJ-79](https://github.com/chenyuxiaojin/CYXJ-79) 仓库，2026-10-13 搬到这里统一维护，旧仓库已归档。

## 两个 Skill

| Skill | 对应视频里的招 | 干什么 |
|-------|--------------|--------|
| [盲区扫描](盲区扫描/SKILL.md) | 干活前 · 第一招 | 进一个你不熟的领域前，先让 AI 找出你的「未知的未知」——没意识到的概念、坑、质量标准，教到你能提出好需求为止 |
| [测验验收](测验验收/SKILL.md) | 干活后 · 第二招 | 一段长任务收尾前，AI 出一份报告 + 测验考你，满分才放行——把「你以为你懂了」的缺口在出事前暴露出来 |

两个 skill 都是**纯指令**，不装任何东西、不跑脚本，复制进去就能用。

## 怎么装

Skill 就是一个带 `SKILL.md` 的文件夹，放进 Claude Code 的 skills 目录即可。

```bash
git clone https://github.com/chenyuxiaojin/cyxj-videos.git
cp -R cyxj-videos/2026-07-09-find-your-unknowns/盲区扫描 \
      cyxj-videos/2026-07-09-find-your-unknowns/测验验收 \
      ~/.claude/skills/
```

不想 clone 整个仓库，也可以在 GitHub 上进这个文件夹，把 `盲区扫描` 和 `测验验收` 两个文件夹里的 `SKILL.md` 手动存到 `~/.claude/skills/盲区扫描/` 和 `~/.claude/skills/测验验收/`。

> `~/.claude/skills/` 是 Claude Code 全局 skill 目录；若不存在，先 `mkdir -p ~/.claude/skills`。只想装其中一个，就只复制那一个文件夹。

装完**重开一个 Claude Code 会话**让它加载。

## 怎么用

装好后，直接说触发词，或在对应场景自然唤起：

- **盲区扫描**：「我不懂 X 但要做 X」「帮我做个盲区扫描」「教我怎么提需求」「这个效果是怎么做出来的」
- **测验验收**：「考考我」「出个测验」「我想确认我真的理解了这次改动」

也可以用斜杠命令 `/盲区扫描`、`/测验验收`。

## 这两招在讲什么

**盲区扫描**——你进一个新领域时满身都是「未知的未知」：不知道该问什么、不知道什么算好、不知道前人踩过哪些坑。这个 skill 先实地侦察（读你的代码/素材、查工具真实版本），再给你一份盲区报告（你的未知未知 / 「好」长什么样 / 你要做的决定），最后一次一题反向采访你，收尾给你一段「你现在可以这样提需求」的话。

**测验验收**——一场长任务下来，AI 做的事往往比你以为的多得多，光看结果只能看到皮毛。这个 skill 先盘点这次到底发生了什么（改了什么、替你拍了哪些板、留了什么隐患），生成报告 + 5~8 道考行为和决策的题，答错就讲到你懂、换题补考，**满分才宣布验收通过**。
