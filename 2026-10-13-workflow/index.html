    提示词

    给每个 claude -p 的提示词长什么样

    8 段每段一份，五六千字，结构一样。Claude Code 只写事实和规矩，它自己觉得画面该怎么做，一句没写进去。

    1. 你负责哪一段帧号范围、这段讲什么；先看现在的画面，判断有没有更好的呈现方式，好的可以留，不好的大胆推翻。
    2. 整条视频这条片讲什么、三条轨是什么、工程说明在哪。
    3. 你这段的口播逐句原文加帧号，还有前一句和后一句。
    4. 现版代码和真素材现在的代码在哪、截好的真网页有哪些；官方页面上没写的，别编。
    5. 作者看这条片时说过的原话原样贴进去，见右下。
    6. 导演一段固定的话，见右上。
    7. 硬性要求只改这段，前后一帧不变；人声只来自口播轨；重点守安全框、不进字幕带；字和数字只用口播和工程文档里有的；网页素材必须是真页面，可以自己开浏览器截；时间按口播里的字对齐，不写死帧数。
    8. 怎么看效果先渲现版看一遍；改完渲关键帧静帧、打开图片自己看，低清渲整段抽帧拼图看节奏；类型检查要过。
    9. 交片写一份出片说明：用大白话说这版怎么呈现、比现版好在哪、改了哪些文件。
    【导演】 画面里出现什么、怎么编排，全部由内容决定；风格只决定它们怎么被画出来、怎么动。 这是一支大师级的动态设计短片，出自顶级动效导演之手。 - 读懂内容，找到一个贯穿全片的视觉构思：让一个主角从头演到尾，画面在它身上一路生长、变化，像一个连续的长镜头。 - 让画面自己把事讲清楚：观众只看画面的变化，就能看懂每一步。 - 每个动作都在表演：有预备、发力、超调和回落，快慢分明；节奏像一首曲子，有起承转合，最大的动作落在高潮。 - 每一帧都经得起暂停：构图饱满，尺度对比大胆，焦点明确，随手截一帧就是一张好海报。 - 第一帧就抓人，结尾是一个精心设计的定格。

    对口型

    实测这条片声音比口型早 2.2 帧，口播轨整体往后挪 2 帧。我听着觉得「声音出现的有点慢」，自己拖回了 0，让 AI「导出一个移动 2 帧的和没有移动 2 帧的小样，分别用数据来告诉我」：

    不挪
    早 2.5 帧
    挪 2 帧
    早 0.5 帧

    中线 = 声画正好对齐。挪后在广电标准（ITU-R BT.1359、EBU R37）的范围内，留 2 帧。

    B6 链

    人声混音

    EQ → 压缩 → 去齿音 → 限制器，是我之前定的一套人声链。这套预设一套上去会把整条时间线的音轨重建，配乐和音效会没掉，所以 AI 在副本上只给口播套链，导出处理好的人声，再放回成片的口播轨；原声留在一条关着的备用轨。套链后 350 Hz 的闷声压下去，1–4 kHz 清晰度提了 2–3 dB。

    它也试过把进链音量提 3 dB 让压缩器多干活，结果去齿音削得太狠、8 kHz 以上掉 4 dB，声音发闷，没用。

    比人声低 10 dB

    音效和配乐

    音效从画面代码里导出 120 个动作点，按清单铺到音效轨。我听完说「很多音效有点太 low」，挑了两种最刺耳的删掉；AI 又给每个点配了第二种音色（B 组）让我切换着听，我说不匹配，撤了；最后从 Mixkit 补了 24 声，5 张章节卡进出统一成一对新声音。

    配乐按我 10-08 定的标准：说话时比人声低 10 dB。低 11–12 dB 手机外放几乎听不到，低 5 dB 停顿处会和人声挤在一起。

    常见问题

    这条视频是怎么做的？

    就是片子里讲的那条流程。口播是我录的，Claude Code 在达芬奇里初剪、把建议删的地方染成玫红色，我看完手动剪气口；包装在 Remotion 里写代码做，8 段画面每段交给一个 claude -p 重做，我逐段在预览里点头后合并；最后回达芬奇，AI 用脚本对口型、混音、铺音效、配乐、量字幕位置、导出和体检。

    这条视频里，人做了什么，AI 做了什么？

    我出想法、录口播、剪口误和气口、给口播调色美颜、看片挑毛病、拍板，4 天里发了 159 条消息；字幕拖上时间线和改字幕样式这两步达芬奇脚本做不了，也是我在界面里点的。其余都是 AI：Claude Code 在 13 段对话里动手 1,898 次；claude -p 另跑了 21 次、操作 1,495 次。

    给 claude -p 的提示词是怎么写的？

    每段一份，五六千字：这段是什么、整条视频讲什么、这段逐句口播和帧号、现版代码和真素材在哪、我看片时说过的原话、一段导演要求、硬性要求、怎么自己看效果、交片时写一份出片说明。Claude Code 自己的想法一句没写进去。看结构和导演那段原文 ↑

    为什么改成 4:3？

    手机竖着刷的时候，1080 宽的屏幕上 16:9 的画面只有 608 高，4:3 有 810 高，画面大了约三分之一。做法是先用一个 xhigh 档的 claude -p 改底座、定版式，再开 8 个 high 档的 claude -p 每段一个并行重排，约 70 分钟、$28。

    发布是 AI 点的吗？

    不是。AI 会自己打开浏览器上传视频、传封面、写标题和简介，最后的发布键是我手动点的。

    剪气口为什么不交给 AI？

    同一句录两遍时，AI 默认留更完整的第二遍，我有时想要第一遍的感觉；我故意停的地方，AI 也会当成停顿剪掉。所以只让 AI 把建议删的地方染成玫红色，我从头到尾看一遍再删。

    一共花了多少钱？

    21 次 claude -p 合计约 $142（按 API 价格折算）：8 段首轮 $84.79，按我的意见续改两段 $4.62，合并后修补 $3.34，MCP 段三档加续改 $20.77，改 4:3 $28.31。Claude Code 主会话的花费没有统计。

    消息条数和操作次数来自 10-10 到 10-13 的 13 段对话记录和 21 次 claude -p 的记录。-p 的用时、花费、打开图片次数取自每次运行的结果记录，按 API 价格折算；续跑的那几次记录的是累计数，按差额算。「三版对照」前两张是用 10-11 当时的代码重新渲的。口型、混音、字幕位置、体检的数字都是导出小样或成片后实测的。「我说过的话」摘自对话记录原文。配图和循环片段从成片截取。
