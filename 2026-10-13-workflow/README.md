# 视频制作流程全公开幕后：讲流程的这条片，也是这么做出来的

<a href="https://chenyuxiaojin.github.io/cyxj-videos/2026-10-13-workflow/"><img src="cover.jpg" width="640" alt="视频制作流程全公开封面"></a>

视频《这是我用 AI 做了5个月的视频制作流程》，5 分 47 秒，4:3。片子里讲的那条流程，就是做这条片时走的流程。

**[看网页版 →](https://chenyuxiaojin.github.io/cyxj-videos/2026-10-13-workflow/)** 有每段的循环小片段、重做前 / -p 版 / 成片三版对照、4:3 版式图、成片时间线和后期实测数据。

## 片子讲的七步

1. **录口播**（我）
2. **初剪 + 染色**（AI）：把素材路径丢给 Claude Code，它在达芬奇里去掉长静音，把建议删的地方染成玫红色。
3. **剪气口**（我）：从头到尾看一遍玫红色再删。同一句录两遍时 AI 默认留第二遍，我有时要第一遍；我故意停的地方 AI 也会剪掉。
4. **Remotion 包装**（AI）：动效和 B-roll 全在 Remotion 里写代码做。
5. **4K ProRes 导出**（AI）：编码快，文件极大。
6. **AI 压缩**（AI）：上一期 9 分 52 秒的 4K ProRes 有 60.5 GB。
7. **浏览器发布**：AI 上传、传封面、写标题简介；**发布键我手动点**。

## 四天

- **10-10**：口播是一周前录的。我问 AI 内容够不够，它试着用克隆音补一段，我听完说内容和声音都不对，还用原来的。我剪完口误；我提出口播、原录屏、AI 录屏分三条轨各自导出，方便 Remotion 取景。背景试了五种模拟模型、三版大海都不要，回到原来的波涌底，只把光往中间挪。
- **10-11**：我发现一段讲达芬奇 MCP 的口播被剪掉了，自己剪好 7 刀插回去。这个开源仓库（davinci-resolve-mcp）我是贡献者之一：简体中文 README 和 resolve-tighten-recording skill 等 [3 次提交合进主分支](https://github.com/samuelgursky/davinci-resolve-mcp/commits?author=chenyuxiaojin)，6 个版本的发布说明点名致谢。8 段画面各交给一个 claude -p 重做，我一段一段看，8 段都要。MCP 段三档各跑一版。下午看到顶流博主都换了 4:3，当晚整条改成 4:3。
- **10-12**：我发现口播没调色美颜，在达芬奇里调好，AI 只换画面不换声音，逐帧核对没错位。安全区拆成两层。选模型换成真 CC 的 /model 窗口，讲设备那段去掉标注，结尾换抖音播放器，进度条里加两个小人。出 4K 母带。
- **10-13**：前一晚 AI 加了 logo 卡和章节卡、没问我就渲了；我说切得太乱，重做。达芬奇后期，导出带字幕和不带字幕两版，各跑一遍音频体检。

## 8 段画面：一段一个 claude -p

整条片做完一版后，Claude Code 把它切成 8 段，每段复制一份独立工程，派一个 high 档的 claude -p，8 个同时跑。首轮合计 $84.79，每段 13–36 分钟，一共打开自己渲的图检查 244 次。跑完 Claude Code 先抽帧自己看，再一次开一个预览给我，附「口播说到 / 旧版 / 新版」对照表，我回「要」才开下一段。8 段都要。

**MCP 段三档各跑一版**：medium 13 分钟 $2.91（头像圆钮来回拨）、high 19 分钟 $3.91（37 / 389 升成大字）、xhigh 43 分钟 $10.44（两面卡翻面）。我挑了 xhigh，提了三条：开头的 3D 倾斜保留；人物不用放大；官方和社区不用来回翻，并排放在左边就好。续改 11 分钟、$3.51。

**合并后再修一次**：8 段拼起来，接缝处有 5 个小毛病（「第 1 遍」卡片空了 3 秒、MCP 段后露出半秒空背景、对话窗空挂 3 秒……），列成单子交给一个 claude -p，11 分钟、$3.34 一次修完。

## 给 claude -p 的提示词

8 段每段一份，五六千字，结构一样。Claude Code 只写事实和规矩，它自己觉得画面该怎么做，一句没写进去。

1. **你负责哪一段**：帧号范围、这段讲什么；先看现在的画面，判断有没有更好的呈现方式，好的可以留，不好的大胆推翻。
2. **整条视频**：这条片讲什么、三条轨是什么、工程说明在哪。
3. **你这段的口播**：逐句原文加帧号，还有前一句和后一句。
4. **现版代码和真素材**：截好的真网页有哪些；官方页面上没写的，别编。
5. **作者看这条片时说过的原话**（原样贴）：
   - 「我觉得整体画面，我的人物就是露脸的部分有点少。不过画面倒还是还行。有点回形针的那种感觉了，但是里面的动画不够精细。」
   - 「素材不对，素材应该是官方的、真实的网页素材，以及真实的仓库页面素材。」
   - 「我的口播小窗口，不要放大我的人物。」
   - 「还是原版吧。只是更朝中心靠一点。」
6. **导演**（固定的一段）：

   > 画面里出现什么、怎么编排，全部由内容决定；风格只决定它们怎么被画出来、怎么动。
   > 这是一支大师级的动态设计短片，出自顶级动效导演之手。
   > - 读懂内容，找到一个贯穿全片的视觉构思：让一个主角从头演到尾，画面在它身上一路生长、变化，像一个连续的长镜头。
   > - 让画面自己把事讲清楚：观众只看画面的变化，就能看懂每一步。
   > - 每个动作都在表演：有预备、发力、超调和回落，快慢分明；节奏像一首曲子，有起承转合，最大的动作落在高潮。
   > - 每一帧都经得起暂停：构图饱满，尺度对比大胆，焦点明确，随手截一帧就是一张好海报。
   > - 第一帧就抓人，结尾是一个精心设计的定格。

7. **硬性要求**：只改这段，前后一帧不变；人声只来自口播轨；重点守安全框、不进字幕带；字和数字只用口播和工程文档里有的；网页素材必须是真页面，可以自己开浏览器截；时间按口播里的字对齐，不写死帧数。
8. **怎么看效果**：先渲现版看一遍；改完渲关键帧静帧、打开图片自己看，低清渲整段抽帧拼图看节奏；类型检查要过。
9. **交片**：写一份出片说明，用大白话说这版怎么呈现、比现版好在哪、改了哪些文件。

## 整条改 4:3

10-11 下午我看到顶流科技博主都换成了 4:3。手机竖着刷时，1080 宽的屏幕上 16:9 只有 608 高，4:3 有 810 高。Claude Code 建议下一条再改，我说：「就这条视频更换成 4:3，你多开几个 -p 去做不就行了吗？5 个不够就 10 个。」做法：一个 xhigh 的 claude -p 改底座、定版式（$8.30），8 个 high 的每段重排一段，约 70 分钟、合计 $28.31。

版式（画布 1440×1080，出 4K 是 2880×2160）：

- **外框 2%**：窗口、截图、画中画最多放到这里。
- **重点框 5%**：正在讲的东西必须在框里，且不进字幕带。判据：被边裁掉、被字幕盖住，观众会不会漏看。这是 10-12 我看顶级 AI 博主的片子后提的：安全区该护的是主体内容。
- **字幕带** y 895–1000。
- **左区** 1012 宽，放网页、软件界面、B-roll。
- **人物竖卡** 340×600，只在右边，人不放大也不缩小。

章节卡 5 张：①② 盖在画面上、口播照常说；③④⑤ 在换气全静处切开插进去，空档只放卡。顶部进度条的分段起点就是章节卡出现的那一帧，两个小人在条里结伴走（「像之前做的《日落大道》MV 那样子……你追我赶，或者走一走又停下来想一想」），结尾跳出来落到播放器上挥手。

## 后期：达芬奇里的活，AI 用脚本做

| 项 | 做法 |
|---|---|
| 对口型 | 实测声音比口型早 2.2 帧，口播轨后挪 2 帧。我觉得「声音出现的有点慢」自己拖回 0，让 AI 导两段小样用数据说话：挪后早 0.5 帧、不挪早 2.5 帧，留 2 帧 |
| 人声混音 | B6 链：EQ → 压缩 → 去齿音 → 限制器。预设会重建整条时间线的音轨，所以在副本上只给口播套链、导出后放回；350 Hz 闷声压下去，1–4 kHz 提了 2–3 dB。试过进链 +3 dB，8 kHz 以上掉 4 dB 发闷，没用 |
| 音效 | 从画面代码导出 120 个动作点铺上；我说「有点太 low」，删了两种最刺耳的；AI 又给每个点配第二种音色让我切换着听，不匹配，撤了；从 Mixkit 补 24 声 |
| 配乐 | 说话时比人声低 10 dB |
| 字幕 | 172 条，每条不超过 16 字；按最终切卡重新生成，第一条从第 0 帧起；字幕中心离底边 265 px（4K），落在 4:3 字幕带正中 |

导出后音频体检：整片 -14.9 LUFS，真峰值 -1.1 dBTP 无削波，配乐比人声低 9.7 dB，左右平衡，抽查 17 处口型 0 位移，44.7 Mbps / AAC 320 kbps，可发。

## 遇到的问题

- 第一次量声音，配乐比人声还响 14 dB、全片削顶 → 配乐先拉到 -24 dB，套完人声链再按「低 10 dB」精调。
- 时间线上贴的是插卡前的旧字幕，片尾提前 7.5 秒 → 按最终切卡重新生成。
- 字幕比 4:3 字幕带高了约 170 px、少了黑底框 → AI 导小样量出来，我在界面里改，它再复量。
- 脚本让达芬奇导出，进度卡在 0% → 在界面上点「渲染」就正常，AI 用模拟鼠标点了一下。
- 音频体检要求配乐低 15–20 dB，和我定的 10 dB 打架 → 以 10 dB 为准，AI 把体检工具门槛改成 9–13 dB 可发。

## 我说过的话（挑毛病的那几句）

- 10-10「他们看起来让我眼睛都好花呀。就是没有那种大海自然的感觉。」→ 模拟模型背景全撤。
- 10-10「这个录屏的也得单独导出……最终得要三个视频，这样子的话，在 Remotion 上它做才好做。」→ 三条轨分开导出。
- 10-11「你用 -p 去单独的看每一段的内容，可不可以有更好的呈现方式，分段去看，一个看一段。」→ 8 段并行重做。
- 10-11「就这条视频更换成 4:3，你多开几个 -p 去做不就行了吗？」→ 整条改 4:3。
- 10-12「这个安全区，是要所有的画面都在里面吗？……是有安全区，但是这个安全区是不是主体内容的安全啊？」→ 安全区拆两层。
- 10-12「一大段没有声音，没有内容在这里干嘛，这么大的错误你说没问题？」→ AI 录屏的 11 秒快放改成只垫口播，哑段删掉。
- 10-13「你的切分有点太乱了。我不喜欢，而且昨天没给我确定就渲染了。」→ 章节卡重做。
- 10-13「你导出一个移动 2 帧的和没有移动 2 帧的小样，分别用数据来告诉我。」→ 见「对口型」。
