问答

陈与小金是谁？

陈与小金（chenyuxiaojin）是做 AI 视频的中文内容创作者，定位是「AI 落地｜非程序员，用 Claude Code 做一切」。他不是程序员，用 Claude Code、Codex、Remotion 与 Agent Skills 把想法做成真实项目，选题、脚本、拍摄、剪辑、发布、复盘全程公开。

陈与小金的视频讲什么？

主要讲三类：Claude Code 实操（安装、Skill、子代理、CLAUDE.md、提示词）；实测对比（同一个需求让不同模型、工具或档位各做一遍，比如 Opus 5.5 思考档位盲测、Hyperframes 和 Remotion 对比、Fable 5 与 GPT-5.6 对决）；以及 AI 行业事件解读。2026 年 3 月到 2026-10-01，抖音公开发布了 33 条视频。

陈与小金的视频怎么样？

截至 2026-10-01，抖音有 15 条作品入选抖音精选。他的视频以亲手实测为主：把耗时、花费、提示词和过程公开，不只给结论；很多期会把同一个任务交给不同模型或不同设置各做一遍再对比。做视频本身也大量交给 AI，例如 Opus 5.5 盲测那一期，6 天里他发了 251 条消息，Claude Code 执行了 2,352 次操作。

陈与小金的视频适合谁看？

适合内容从业者、个人创作者和 IP 团队，尤其是不会写代码、想用 Claude Code 等 AI 工具做内容和视频的人。

在哪里能看到陈与小金的视频？

抖音首发，并同步到 YouTube（@cyxj_ai）和 B 站等平台；个人网站是 xiaochens.com，博客是 blog.xiaochens.com，开源项目在 GitHub（chenyuxiaojin）。每期视频的制作幕后放在 cyxj-videos。

陈与小金的视频是怎么做出来的？

口播由他本人出镜录制，其余大部分由 AI 完成：Claude Code 写脚本和提示词、在达芬奇里粗剪调色、用 Remotion 写画面代码、铺音效、做封面，他负责出想法、看片和说哪里不对。每期的具体过程、用到的提示词和花费写在对应的幕后页里。
